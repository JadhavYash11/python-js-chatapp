# 💬 Python Real-Time Chat App

A real-time chat application built using **Flask** and **Socket.IO** that allows multiple users to chat instantly with usernames and avatars.

---

## 🚀 Features
- Real-time messaging using WebSockets
- Automatic user assignment
- Username update support
- Join / leave notifications
- Clean and responsive UI
- Multiple users supported via browser tabs

---

## 🛠 Tech Stack
- Python
- Flask
- Flask-SocketIO
- HTML, CSS, JavaScript
- Socket.IO
